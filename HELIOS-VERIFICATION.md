# Project Helios software verification

Fabrication is on hold while the complete design is developed and verified in software. Before release, each electrical block needs an executable model, measured or published inputs, numeric pass criteria, fault cases and a review of what the model omits. Tie results to the revision of the schematic, board, BOM and firmware. Record changes that invalidate a previous result.

CI is configured to run the base circuit regression on ngspice 42 and all four firmware images against the Unicorn register fixture. The KiCad 10 job checks ERC, DRC and schematic parity on the parent and rear-bypass projects. It also checks the rail-protection schematic and its exported netlist, then extracts the saved main-board copper for a DC smoke test. The locally published vendor replays use ngspice 47 with TI models in PSpice compatibility mode or Xyce with the documented adaptations. The firmware fixture uses scripted peripheral behavior. Actual HRTIM timing, independent hardware shutdown and physical fault response need bench correlation. Record the solver version, model source and result for each claim. [CI workflow](.github/workflows/verify.yml) · [Circuit checks](circuits/battery-port/README.md) · [Firmware tests](circuits/battery-port/BENCH-HRTIM.md)

The software release evidence supports fabrication review. It cannot establish physical shock safety, insulation integrity or workmanship. After fabrication, a qualified power-electronics lab should own the high-energy power-up and safety tests. [Safe isolation and stored electrical energy](https://www.hse.gov.uk/pubns/priced/hsg85.pdf)

## Repository audit follow-up

The follow-up retains the original BOM and trace-only audit evidence. The filled main board has a new set of local checks. GitHub Actions passed on the preceding audit revision. [Hosted run for 06c1a5c](https://github.com/ramamoo3/Helios/actions/runs/44744275126)

| Finding | Verified change or remaining work |
| --- | --- |
| Return planes, power copper, clearance and assembly | The main board carries the tested split planes, wider inner runs, four mounting holes and three fiducials. The saved board passed KiCad checks. The modeled DC paths match the historical trial within numerical tolerance. Four 10 MHz commutation loops completed at 1.5 mm mesh pitch. Filament warnings, finer-mesh solver timeouts, steady-state thermal limits and assembly fit remain open. [PCB and extraction](circuits/battery-port/BENCH-PCB.md#return-plane-trial-and-design-rules) |
| Power switch selection | Both TO-220 devices passed the standalone startup matrix. The routed 100 V TO-220 candidate still has inconclusive high-side-short and forced-current cases. The SON rear-bypass coupon passed 16 reduced-driver resistive and short runs with a 39 Ω low-side gate resistor. An inductive candidate passed both directions at 25 °C and 100 °C at 125, 250 and 500 ps in the reduced driver. The highest drain peak was 33.44 V. An ST diode model also passed a hot high-side check with assumed loop inductance. Layout extraction, faults, safe operating area and independent-model verification remain open. The vendor-driver rail still dipped below 9.2 V at finer steps with the direct pin bypass. [TO-220 results](circuits/battery-port/BENCH-PARTS.md#100-v-to-220-candidate) · [SON inductive trial](circuits/battery-port/BENCH-SECONDARY-PROTECTED.md#inductive-commutation-stress) |
| BOM and shunts | All 29 audited capacitor positions carry matching manufacturer, MPN and voltage fields in the KiCad schematic and PCB. The native BOM export reproduced the expected counts. The 0.5 mΩ parent R30 and the 5 mΩ isolated-coupon shunt have distinct roles. The measured effective bootstrap capacitance and independent verification of the populated parts remain open. Independent-switch placement simulations bound the capacitor pulse and opening stress. Actual driver turn-off, a physical backup interrupter, fuse coordination and routing remain open. The complete energized standby draw and enclosure depth still require qualification. [Architecture](HELIOS-ARCHITECTURE.md) |
